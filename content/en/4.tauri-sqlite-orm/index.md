# Welcome to Tauri SQLite ORM
Welcome to the official documentation for Tauri SQLite ORM. This library is a Drizzle-like, type-safe ORM designed specifically for use with Tauri v2's `@tauri-apps/plugin-sql`.

Our goal is to provide a simple, powerful, and developer-friendly way to interact with your application's SQLite database. By leveraging TypeScript, we offer strong type safety and autocompletion, catching errors at compile time and making your development workflow faster and more reliable.

### Core Features
- **Drizzle-like Schema:** Define your database schema using a familiar, chainable API.
- **Type-Safe Query Builder:** Build SQL queries with TypeScript, ensuring type safety and autocompletion for columns, conditions, and results.
- **Simplified Migrations:** Automatically detect schema changes and migrate your database to keep it in sync with your models.
- **Lightweight & Performant:** Designed as a thin, efficient layer over the official Tauri SQL plugin, ensuring minimal overhead.
