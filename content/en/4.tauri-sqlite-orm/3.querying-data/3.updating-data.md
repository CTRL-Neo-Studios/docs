# Updating Data (UPDATE)
The `db.update()` method is used to modify existing records in a table. It provides a query builder that requires a `.set()` call to specify the changes and typically a `.where()` clause to target specific rows.

## Basic Update
To update one or more rows, chain the `.set()` and `.where()` methods.

```ts
import { db } from '$lib/db';
import { users } from '$lib/db/schema';
import { eq } from '@type32/tauri-sqlite-orm';

// Update a user's name based on their ID
const result = await db.update(users)
  .set({ fullName: 'Jane Smith' })
  .where(eq(users.id, 1))
  .execute();

console.log(result);
// [{ rowsAffected: 1 }]
```

> **Warning:** Be very careful to include a `.where()` clause. Without it, the `UPDATE` statement will apply to **every row** in the table.

## The `.set()` Method
The `.set()` method takes an object where keys are the `camelCase` column names from your schema, and values are the new data you want to set. The object is typed based on your schema's `InferInsertModel`, so you get full autocompletion and type safety.

```ts
// You can update multiple columns at once
await db.update(users)
  .set({
    fullName: 'Jane Smith',
    status: 'inactive' // Assuming 'status' is a column
  })
  .where(eq(users.id, 1))
  .execute();
```

## Automatic Updates with `$onUpdateFn`
If you defined a column with the `.$onUpdateFn()` modifier in your schema, its value will be automatically updated whenever a row is modified via `db.update()`, even if you don't specify it in the `.set()` call. This is perfect for an `updatedAt` timestamp.

```ts
// Schema definition for reference:
export const users = sqliteTable('users', {
  // ...
  updatedAt: integer('updated_at', { mode: 'timestamp' })
    .$onUpdateFn(() => new Date()),
});

// This query will automatically update the `updatedAt` column for user 1
await db.update(users).set({ status: 'active' }).where(eq(users.id, 1)).execute();
```

## Returning Updated Data
Similar to `insert`, you can retrieve the data from the rows that were just updated using `.returning()` or `.returningAll()`. This is useful for getting the final state of a record after a change.

```ts
// Update the user and get the full updated record back
const [updatedUser] = await db.update(users)
  .set({ fullName: 'Jane S.' })
  .where(eq(users.id, 1))
  .returningAll();

console.log(updatedUser);
// { id: 1, fullName: 'Jane S.', ..., updatedAt: Date(...) }

// Or just get specific fields
const [updatedName] = await db.update(users)
  .set({ fullName: 'Jane Smith' })
  .where(eq(users.id, 1))
  .returning('id', 'fullName');

console.log(updatedName);
// { id: 1, fullName: 'Jane Smith' }
```
