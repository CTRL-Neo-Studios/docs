The `db.delete()` method is used to remove records from a table. It provides a query builder that is almost always used with a `.where()` clause to specify which rows to delete.

## Basic Delete
To delete one or more rows, call `db.delete()` and specify your targets with a `.where()` condition.

```ts
import { db } from '$lib/db';
import { users } from '$lib/db/schema';
import { eq } from '@type32/tauri-sqlite-orm';

// Delete the user with ID 1
const result = await db.delete(users).where(eq(users.id, 1)).execute();

console.log(result);
// [{ rowsAffected: 1 }]
```

### **DANGER**: Deleting All Rows

If you call `.execute()` on a `delete` query **without a `.where()` clause**, you will **delete every single row** from the table. This is a destructive and irreversible operation. Always be sure to filter your `delete` statements appropriately.

```ts
// !! DANGER !!
// This will empty the entire 'users' table.
await db.delete(users).execute();
```

## Returning Deleted Data
Sometimes it's useful to get the data from the rows you just deleted, for logging purposes or to implement an "undo" feature. You can use `.returning()` and `.returningAll()` to retrieve this data as part of the delete operation.

```ts
// Delete a user and get their data back in the same query
const [deletedUser] = await db.delete(users)
  .where(eq(users.id, 2))
  .returningAll();

if (deletedUser) {
  console.log(`Deleted user: ${deletedUser.fullName} (ID: ${deletedUser.id})`);
  // You could now, for example, show a "User deleted. Undo?" toast message.
}
```

You can also return only specific columns from the deleted record.

```ts
// Get just the email of the deleted user
const [deletedRecord] = await db.delete(users)
  .where(eq(users.email, 'stale-user@example.com'))
  .returning('email');

if (deletedRecord) {
    console.log(`Removed stale account: ${deletedRecord.email}`);
}
```
